# English Lab · My English Adventure (Book 1)

Interactive listening lab for the Student's Book and Workbook.
Each QR code in the book opens one track: listen (with voices), read the text, complete the task, do the quiz, and role-play the conversation.

## Publish on GitHub Pages (free)
1. Create a free account at github.com and click **New repository** (name: `english-lab`, Public).
2. Click **Add file → Upload files**, drag `index.html` and `README.md`, and click **Commit changes**.
3. Go to **Settings → Pages**. Under *Branch*, choose `main` and `/ (root)`, then **Save**.
4. After 1–2 minutes your lab is live at `https://YOUR-USERNAME.github.io/english-lab/`.
5. Open `https://YOUR-USERNAME.github.io/english-lab/#qr` and print the QR codes for the book.

## Track addresses
Each track has its own address, e.g. `.../#u01-l` (Unit 1 listening), `.../#u01-c` (Unit 1 conversation), `.../#wb01-1` (Workbook Track 1.1).

## Notes
- Voices use the device's built-in text-to-speech (works best in Chrome, Edge and Safari).
- The 🎤 microphone check works in Chrome and Edge; other browsers show an "I said it" button.
- Progress (stars) is saved on each student's device.
